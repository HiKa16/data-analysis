# data-analysis

- ``electriciteFR2023.ipynb`` : analyse exploratoire des donnéees de consommation et de production d'électricité en France en 2023 ([source](https://www.rte-france.com/eco2mix/telecharger-les-indicateurs)).

- ``electriciteEU.pbix (+ .pdf)`` : rapport Power BI qui présente les données de consommation et de production d'électricité dans les pays d'Europe depuis 2016 ([source](https://analysesetdonnees.rte-france.com/europe/synthese-europe)).
